## 📄 **Dynamic Instructions**

* **English:** Instructions that can change or update during a process so the system can adapt to new requirements or situations.
* **Urdu:** Aisi hidaayatein jo kaam ke dauran badal sakti hain taake system naye requirements ya halat ke mutabiq kaam kar sake

### **2. Why We Use Them**

* 🔹 **Flexibility** — System adjusts to changing needs.
* 🔹 **Personalization** — Output can be tailored instantly.
* 🔹 **Efficiency** — No need to restart the process for new instructions.
* 🔹 **Better Control** — User can steer the task midway.


### **3. How They Work**

1. **Initial Instructions** — Start with a base set of rules
2. **Update During Process** — Change or add new rules
3. **System Adapts** — The ongoing task follows the latest instructions


### **4. Examples**

* 🤖 **Chatbot Example:**
  Start: "Give detailed answers."
  Midway: "Switch to short answers only."
  Result: Bot immediately changes reply style.

* 📊 **Data Processing Example:**
  Start: Sort data by date.
  Midway: Change to sort data by name without restarting the process
