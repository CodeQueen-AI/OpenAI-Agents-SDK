🔷 **Agent** – A smart helper that follows instructions to do specific tasks

🔷 **Handoff** – When one agent passes the work to another agent to handle

🔷 **Runner** – The system that starts and controls agents when they work

🔷 **Tool** – A small function that an agent can use to do something

🔷 **Tool Calling** – When an agent decides to use a specific tool to get work done

🔷 **Tool Integration** – Connecting a tool with an agent so it can use it

🔷 **Tool Arguments** – The input or details a tool needs to work properly

🔷 **Multiple Tools** – When an agent has more than one tool it can use

🔷 **Reusable Tools** – Tools that can be used in different projects or by different agents

🔷 **Parallel Tools** – Tools that can run at the same time for faster results

🔷 **Context Management** – Storing and using important details so the agent remembers the situation

🔷 **Dynamic Instructions** – Changing an agent’s instructions while it’s working
